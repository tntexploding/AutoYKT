| 配置迁移 | 输出到其他目录后，相对模板、提示词和数据库路径改变目标 | 导出前按原配置位置解析为绝对路径，不搬动或覆盖原文件 |

## 真实使用的边界

1. 纯像素变化只能证明页面变化，不能证明平台接受了答案。正式接管应配置明确的成功状态模板，并确认该模板不会出现在答题前。
2. `rearm` 应选择题号或稳定题干等题目身份区域，排除选中高亮、倒计时、动画和结果反馈；选项点击后的正常视觉变化必须与题面检查阈值一起标定。
3. 模板和坐标仍依赖显示器、DPI、浏览器缩放、窗口位置及主题。本轮没有真实网页端到端验收，应依次执行 `check`、`run --detect-only`、模型干运行，再验证真实点击闭环。
4. 知识检索仍为课程隔离的本地词法检索；扫描版 PDF 没有文本层时仍需 OCR。当前交互题型仍为单选，多选、填空和 DOM 驱动没有在本轮引入。
5. 已取消当前索引中的旧截图跟踪，但历史提交仍保留历史文件。本轮没有修改历史或发布任何内容。

## 第三轮：有人监控的课堂主流程

按前几次真实课堂有人驻留的范围，补齐提交后的关闭结果、继续和下一题动作，以及加载等待、人工处理和课堂结束识别。所有动作来自私有页面配置，执行前再次核对状态；同一个结果动作每题最多一次，并提供不调用模型或鼠标的独立预览。

新增整题、OCR/检索和模型阶段预算。模型队列与有限重试共享截止时间，到期取消未完成请求，对及时返回的结果按原共识门槛判定。回归发现并修复了外层计时器先于模型汇总取消、误丢可用答案的问题。临时模型错误可以重试，入口、选择和提交不随模型请求重放。

新增私有操作检查点：输入意图先落盘，提交不明时等待人工处理；已验证记录可在重启后恢复旧题基线和已执行的结果操作。人工 `recover --skip-current` 记录当前页跳过基线并关联原报告，不点击或补提交。窗口暂时不可用可恢复检测，全部页面结束或需要人工处理时监控命令退出。

- Pylint 10.00/10，退出码 0；Pyright 0 errors、0 warnings；Pyink 的 59 个 Python 文件无需格式调整；59 个文件通过 Python 3.10 语法解析。
