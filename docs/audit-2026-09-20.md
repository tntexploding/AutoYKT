# 阶段审计与部署验收（2026-09-20）

本次审计覆盖当前工作区的完整 v0.2 实现：全部应用模块、入口与标定脚本、配置和安装定义、测试、公开文档。保留此前开发成果，集中修复实际运行与全新部署中的问题；本阶段结束后以现场使用和缺陷修复为主。

## 本轮修复

| 范围 | 问题与处理 |
| --- | --- |
| 全新部署 | 干净 Python 3.14 环境无法安装当前 RapidOCR 依赖。把项目支持范围明确为 3.10–3.12，推荐并实际验证 64 位 3.12；运行依赖统一由 `pyproject.toml` 声明 |
| 指定页面检查 | `check --profile` 的资源检查可能检查其他活动页面，遗漏指定页面的缺失模板。现在只检查指定候选页，检查副本不改变其启用状态；正式检查仍拒绝禁用页面 |
| 私有密钥 | 拒绝空白内联密钥，去除首尾空格；导出仍排除密钥，不覆盖用户的私有配置 |
| 换题等待 | 已完成页面停留超过换题等待时间属于正常课堂状态。改为一次信息日志并持续等待，不再误计为错误；不会重新请求模型或点击 |
| 最终报告 | 关闭过程中排空观察事件后重新评估结果，避免晚到错误已计数、但最终评估仍显示通过 |
| 首次标定 | 字母采集从 A–E 扩展到 A–Z，避免 F/G 覆盖前面的字母；增加已选中/未选中背景采色与完整按钮尺寸采集，保留未修改的标定和私有密钥 |
| 安装包验证 | 测试不再自动把源码目录插到导入路径前；在独立环境中对真正安装的 wheel 运行完整测试，避免源码掩盖打包问题 |
| 使用文档 | 重排安装、私有配置、首次标定、检查、两小时启动、恢复和升级步骤；说明环境变量继承、`.env` 不自动加载和正式提交的验证边界 |

审计也检查了答案严格解析与整组选项投票、限时请求及取消、动态定位与反选、输入前页面复核、完成反馈、检查点与进程互斥、事件关闭、课程数据隔离、通知和错误输出。保留针对这些行为的回归测试，没有为本轮发布引入新的大规模功能。

## 交付与实际使用边界

全新部署按照 [README](../README.md)，首次现场标定按照 [部署指南](deployment.md)。标定完成后先运行 `start-class.cmd --check`，再用 `start-class.cmd` 启动默认两小时的独立流程。

尚需实际课堂验收的是：新题提示进入题面、在真实倒计时内选择与提交、平台确认完成、连续下一题，以及真实两小时的暂停与遗漏情况。第一次正式使用仍需人工在场核对，保留私有会话报告。

窗口需完整可见；程序不能操作被遮挡、最小化或隐藏标签页。预算从本地发现题目/提示开始计时，不直接读取平台截止时间。默认文本 Flash 对图表与公式的理解受 OCR 限制；模型得票最多不等于答案正确。遇到不确定输入或无法验证提交时，保留检查点并要求人工确认，具体见 [课堂运行](class-session.md)。
